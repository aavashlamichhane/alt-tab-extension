# Edge Alt-Tab Extension

An extension for Microsoft Edge that implements "Most Recently Used" (MRU) tab switching, mimicking the Alt-Tab behavior of Windows/Ubuntu.

## Features
- **MRU Order:** Always switches back to your last-used tab.
- **Visual Overlay:** Shows a menu of recent tabs (Favicon + Title).
- **Smooth Cycling:** Hold `Alt` and tap `Q` repeatedly to cycle. Release `Alt` to switch.
- **Escape to Cancel:** Press `Esc` while the menu is open to stay on the current tab.

## Default Keyboard Shortcut
- **Alt + Q** (This can be customized in `edge://extensions/shortcuts`)

## Installation (Developer Mode)
1. Open Microsoft Edge.
2. Go to `edge://extensions/`.
3. Enable **Developer mode** (bottom left).
4. Click **Load unpacked**.
5. Select the `alt-tab-extension` folder.

## How to use
- Press **Alt+Q** once to switch to the most recently used tab.
- Hold **Alt** and press **Q** multiple times to see a list of recent tabs and cycle through them.
- Release **Alt** to perform the switch.
